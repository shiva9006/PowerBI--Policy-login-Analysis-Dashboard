
# Policy Login Analysis Dashboard
## Project Overview
This project is an interactive Power BI dashboard developed to analyze policy login performance and provide actionable business insights. The dashboard helps monitor login trends, policy status, advisor performance, and key business metrics through interactive visualizations.

## Tools Used
- Power BI
- Power Query
- DAX
- Excel

## Features
- Policy Login Overview
- Total Policies Logged
- Advisor Performance Analysis
- Branch-wise Analysis
- Monthly Login Trends
- Policy Status Analysis
- Interactive Filters (Slicers)
- KPI Cards

## Skills Demonstrated
- Data Cleaning

- DAX Calculations

- Data Visualization
- Business Intelligence

## Dataset
The dashboard is built using a policy login dataset containing policy, advisor, branch, and login-related information.
